# Бриф: окна поселения, построек и войска

Листы поселения, постройки и отряда («Королевство» по мотивам Manor Lords) уже в облике «Гравюра»: кожаные пластины
с кольцом одобрения, гнёзда-сокеты с картинками, латунные пипсы уровней, вкладки-ярлыки (стили `settlement.css`,
`army.css` в `_ds_bundle.css`, классы `.sv-*`, `.bl-*`, `.ar-*`, `.bt-*`). А **окна, которые из них открываются**, —
голые формы Foundry: подпись слева, поле справа, серая кнопка внизу. Они выпадают из облика. Задача — дать им облик
листов, одним семейством.

## Окна (всё, что открывается из трёх листов)

Ввод (диалог с полями и кнопкой действия):
- **Внести в казну / Взять из казны** (лист поселения). Поле «Сколько Богатства» (число), подсказка
  «1 Богатство = 500 оренов. Из кошелька: Геральт». Кнопка «Внести» / «Взять».
- **Набор войска: Липов** (лист поселения, вкладка «Войско»). Поля: «Откуда» (список: Ополчение — есть 30 чел.;
  Семьи без дела — 2 (по 5 бойцов); Наёмники — 0.04 Богатства за бойца), «Сколько» (число; подсказка «для семей — число
  семей»), «Куда» (Новый отряд или существующий), «Род войск» (пехота, копейщики, лучники, конница), «Название».
  Подсказка про наёмников. Кнопка «Набрать». Самое сложное окно — образец для остальных.
- **Событие: Липов** (ведущий). Список событий («Случайное из подходящих», «Засуха (сейчас не к месту)»…), подсказка
  «Правитель решит на листе поселения». Кнопка «Случилось».
- **Заказ: Меч** (лист постройки, перетащили предмет). «Для кого» (список персонажей), «Сколько», подсказка цены
  «За штуку: Железо 2, Древесина 1 со склада «Липов», 1 нед. работы». Кнопка «Заказать».
- **В поход: Ополчение Липова** (лист отряда). «Припасов на недель» (число), подсказка про еду. Кнопка «В поход».
- **Осада: Ополчение Липова** (лист отряда). «Какое поселение» (список), подсказка о последствиях осады. «Осадить».

Подтверждение (вопрос и две кнопки — «Да» и «Нет», по умолчанию «Нет»):
- **Снести: Лесопилка** — «Постройка будет снесена; потраченное не вернётся». Разрушительное.
- **Распустить: Ополчение Липова** — «Бойцы вернутся в Ополчение поселения. Снаряжение не вернётся на склад».
- **Удалить: отряд** — «Отряд исчезнет вместе с бойцами». Разрушительное.
- **Летопись — в журнал** — «Все недели с листа перейдут в журнал «Летопись», а лист очистится».
- **Под стенами** — «Отряд подошёл к «Липов». Начать осаду?»
- **Отряды сошлись** — «…Начать битву на этом месте?», подсказка «В бою — все отряды в 4 клетках».

Меню и мелочи:
- **Меню отряда по правой кнопке** (список войска, окно битвы): «Лист отряда», «Сменить картинку», «Настроить жетон»,
  «Распустить», «Удалить» — со значками. Сейчас — стандартное контекстное меню Foundry.
- **Выпадающие списки** в этих окнах — уже тёмные; пункт под курсором и выбранный — в облике.

## Чего хочется

- Одно семейство: шапка окна с названием (Vedmak Display) и, где есть, картинкой поселения/отряда в сокете `.sv-sock`;
  поля — подписью над полем (`.cap`), не «подпись слева — поле справа»; подсказка — мелко под полями.
- Числа (сколько, недель) — крупно, как `.big` пластин; рядом то, что изменится (казна 12 → 9, Ополчение 30 → 20).
- Кнопка действия — `.go-btn`; у разрушительного подтверждения («Снести», «Удалить») — киноварь (`--vd-blood`),
  и по умолчанию остаётся «Нет».
- Ширина окна Foundry 400–480 px; всё должно помещаться без прокрутки.

## Ограничения

- Только облик «Гравюра»: токены `--vd-*` и `--sv-*`, шрифты Vedmak Display / Vedmak Sans, свет сверху, металл цифр.
- Латунь — уровни и Удача; киноварь — разрушение и урон; зелень — рост, прибавка.
- Разметка — обычный HTML на классах системы (компонентов React нет); окно — каркас Foundry
  `.application.vedmak.sheet > .window-content`, шапка `header.window-header`, кнопки `footer.form-footer`.
- Не нагружать: анимации только transform и opacity; без `:has()` и широких `body … *` селекторов.

## Что отдать

Макеты окон в этом проекте: «Набор войска» (образец), «Внести в казну», «Заказ», «Снести» (разрушительное
подтверждение), «Распустить» (обычное), меню отряда. Остальные — по их образцу; в систему переносит Claude Code.
