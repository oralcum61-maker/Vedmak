# «Ведьмак: НРИ» — система для Foundry VTT v14

Неофициальная фанатская система по настольной ролевой игре «Ведьмак» (R. Talsorian Games),
целиком на русском. Некоммерческая: не продаётся и не собирает пожертвований.

## Установка

В Foundry VTT v14 на экране запуска: **Игровые системы → Установить систему**
(Game Systems → Install System). В поле **URL манифеста** (Manifest URL) внизу окна вставьте ссылку
и нажмите «Установить»:

```
https://github.com/oralcum61-maker/Vedmak/releases/latest/download/system.json
```

Foundry скачает последнюю версию и будет сам предлагать обновления. Все версии — на странице
[Releases](https://github.com/oralcum61-maker/Vedmak/releases).

## Права

- Правила и тексты — © R. Talsorian Games и правообладатели вселенной «Ведьмак».
- Значки предметов и знаков в `assets/fan/` — материалы игр The Witcher, © CD Projekt RED,
  используются как фанатский контент по правилам CDPR (см. `assets/fan/О-ПРАВАХ.txt`).
  Там же арты рас и профессий и портреты бестиария — карты Гвинта из фанатского компендиума
  BS & Tobi «The Witcher Compendium».
- Бестиарий, случайные таблицы, генераторы и памятки по правилам перенесены из того же
  компендиума BS & Tobi; у записей стоит пометка об этом.
- Жетоны существ в `assets/tokens/` — из компендиума BS & Tobi, среди них наборы 2-Minute Tabletop
  с лицензией только для личного использования (см. `assets/tokens/О-ПРАВАХ.txt`). **В выпуски системы
  они не входят**: сборка `tools/release.mjs` исключает папку, а в бестиарии ставит вместо жетонов портреты.
- Фактуры (кожа, железо, дерево, камень, полотно, бумага, пергамент, латунь) в `assets/textures/`
  и собранные из них баннеры компендиумов в `assets/banners/` — CC0 с ambientCG. Баннеры магии, рас,
  профессий, оружия, брони, бестиария, таблиц, генераторов и памяток — картины, сгенерированные нейросетью
  Nano Banana Pro (Google) по заказу автора;
  на баннере рас — медальон ведьмака по дизайну CD Projekt RED (фанатский контент).
- Шрифты Forum и PT Serif в `fonts/` — SIL Open Font License 1.1.
- Обложка системы в `assets/cover/` (фон новых миров и плитка на экране запуска) сгенерирована
  нейросетью Nano Banana Pro (Google) по заказу автора. Медальон на ней повторяет дизайн CD Projekt RED —
  это фанатский контент, как и `assets/fan/`.

## Что внутри

Персонажи и чудовища, бой с критическими ранениями, магия, ремесло и алхимия,
мастер создания персонажа, боевой худ и пятнадцать компендиумов — среди них бестиарий
на 275 существ и НИП, случайные таблицы, генераторы и памятки по правилам.

Лист собран из материалов: кожа переплёта и тиснёные закладки, вороненая сталь вкладок и полос,
холст снаряжения, пергамент магии, бумага дневника, бронза счётчиков — четырнадцать фактур,
все CC0 с ambientCG (`assets/textures/ИСТОЧНИКИ.txt`).

В компендиумах — корник и предметное из официальных дополнений: «Снаряжение ведьмака»,
«Журнал ведьмака» (A Witcher's Journal), «Фургончик Родольфа», «Профессиональные инструменты»,
«Книга сказаний» (A Book of Tales) и «Том Хаоса» (A Tome of Chaos) — и магический рынок,
и вся магия: заклинания мага, инвокации жреца и друида, ритуалы, порчи, магические дары
и тёмные искусства — некромантия и гоэтия. У каждой записи указана книга и страница,
так что при игре только по корнику лишнее видно сразу.

Дорожная карта и состояние работ — `docs/PLAN.md`.
