# Проверка системы

## Запуск

Из корня репозитория (`D:\Witcher\vedmak` на компьютере автора):

```
node tools/check.mjs                  # всё
node tools/check.mjs code templates   # только выбранные разделы: code, templates, packs
```

Код выхода 1 — есть ошибки, коммитить нельзя. Предупреждения код выхода не меняют.

- **Шаблоны компилируются**, только если найден `handlebars`. На компьютере автора он берётся из Foundry
  (`FOUNDRY_APP`, по умолчанию `D:/FoundryVTT-WindowsPortable-14.365/App/resources/app`). В облачной
  сессии поставь его во временную папку и укажи её:
  `npm install --no-save --prefix /tmp/hbs handlebars@4`, затем `NODE_PATH=/tmp/hbs/node_modules node tools/check.mjs`.
- **Значки Foundry** (`icons/…`) проверяются только при найденной папке Foundry. В облаке будет одно
  предупреждение «не проверено» — это нормально.

## Что делать с ошибками

| Сообщение | Где чинить |
|---|---|
| `[код] …: SyntaxError`, «не экспортирует», «нет модуля» | в указанном модуле |
| «настройка … не зарегистрирована» | `game.settings.register` в `vedmak.mjs` |
| «подшаблон … не зарегистрирован в TEMPLATE_PATHS» | добавить путь в `TEMPLATE_PATHS` в `module/helpers.mjs` |
| «схема …: поля нет в схеме», «не число», «вне списка choices» | модель в `module/data/…` **или** генератор записей |
| «битая ссылка», «нет картинки», «нет значка Foundry» | генератор в `D:\Witcher\_tools` (`gen_*`, `dlc_*`, `bs_*`, `fix_icons.py`) |

**`packs-src` руками не править:** его перегенерируют скрипты `_tools`, и правка пропадёт (см. `CLAUDE.md`).
В облачной сессии скриптов нет. Опиши, что и в каком генераторе поправить, и запиши это в очередь
`docs/PLAN.md` — починят на компьютере автора.

## Предупреждения

- **Повторы значков** — известная очередь (PLAN 4.23). Если твоя правка добавила новый повтор, разберись.
- **«у кнопки data-action не найден обработчик»** — эвристика. Проверь, что действие есть в `actions: {…}`
  листа или окна или его обрабатывает сам Foundry. Если это встроенное действие, добавь его в
  `BUILTIN_ACTIONS` в `tools/check.mjs`.

## Чего проверка не видит

Поведение в игре: окна, броски, применение урона, вид листа. После правок, влияющих на игру, скажи
пользователю, что именно открыть и нажать в Foundry, чтобы убедиться, что всё работает.
