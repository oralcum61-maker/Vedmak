# Выпуск версии

Ссылка для установки в Foundry (манифест) всегда одна и ведёт на последний выпуск:
`https://github.com/oralcum61-maker/Vedmak/releases/latest/download/system.json`.

## Порядок

1. `node tools/check.mjs` — без ошибок (навык `/check`).
2. Поднять `version` в `system.json`: исправления — третья цифра (0.1.0 → 0.1.1), новые возможности —
   вторая (0.1.1 → 0.2.0). Тег обязан совпадать с версией, иначе сценарий выпуска остановится.
3. Записать в `docs/PLAN.md`, что вошло в версию.
4. Коммит «Выпуск X.Y.Z», отправка в `main`.
5. Тег и его отправка — это и есть команда на выпуск:
   ```
   git tag vX.Y.Z
   git push origin vX.Y.Z
   ```
6. Дождаться сценария «Выпуск» в GitHub Actions (`.github/workflows/release.yml`). Он проверяет систему,
   собирает её через `tools/release.mjs`, архивирует и создаёт выпуск с двумя файлами: `system.json` и
   `vedmak.zip`. Если сценарий упал — прочитай журнал и почини. Тег с ошибкой удали
   (`git push origin :refs/tags/vX.Y.Z`, `git tag -d vX.Y.Z`) и поставь заново после исправления.
7. Сказать пользователю: установленная система обновится кнопкой «Обновить» на экране запуска Foundry.

## Что входит в выпуск

`tools/release.mjs` копирует файлы из git без `EXCLUDE`: служебные папки, `packs-src`, `tools`, `design`, `docs`
и **жетоны `assets/tokens/`** — лицензия 2-Minute Tabletop запрещает их раздавать. В бестиарии жетоны
заменяются портретами, и пакет пересобирается. Если в систему добавляется ресурс, который нельзя
раздавать, впиши его в `EXCLUDE`.

Проверить сборку без выпуска можно локально: `node tools/release.mjs X.Y.Z` (нужен `FOUNDRY_APP` с
`classic-level`). Результат — `dist/vedmak/` и `dist/system.json`; `dist/` в git не попадает.
