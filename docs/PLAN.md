# «Ведьмак: НРИ» для Foundry VTT v14 — план

Система пишется **с нуля**, только на русском, по книгам из `D:\Witcher` (корник — через конспект `D:\Witcher\_notes\kornik.md`, ссылки вида «стр. N» — это страницы русского корника).
Референсы (читать, но не копировать код — у основной системы GPL-3.0):
- `D:\Witcher\_ref\TheWitcherTRPG` — комьюнити-система v14 (как решены карточки атаки/защиты, криты, ремонт, расследования);
- `D:\Witcher\_ref\Deathmarch-Witcher-TRPG` + `_ref\dm-compendium-json` — форк с огромным английским компендиумом (у каждого предмета «книга + страница») — источник для сверки полноты контента.

## Принципы
- Правила как в книге (RAW). Необязательные правила (адреналин, словесная дуэль, «чудовища из книг», расследование) — переключатели в настройках.
- Всё считается автоматически, но у Мастера всегда есть ручная правка.
- Без внешних зависимостей и без сборки: ES-модули `.mjs`, Handlebars, CSS. Компендиумы — из `packs-src/*.json` скриптом `tools/build-packs.mjs` (LevelDB через `classic-level` из самого Foundry).
- Модели данных на `TypeDataModel` (без template.json), листы на `ApplicationV2`.

## Этапы
### 0. Каркас ✅ готово (проверено на Foundry 14.365)
- system.json, точка входа `vedmak.mjs`, русская локализация типов, `CONFIG.VEDMAK`, `game.vedmak` (performCheck, rollD10).
- Параметры, производные (стр. 47–48), 52 навыка по параметрам, сложные помечены (стр. 49–56).
- Порог ранения (Реа/Лвк/Инт/Воля ×½) и «при смерти» (всё ×⅓) — сразу в итоговых значениях и бросках.
- Лист персонажа: параметры, производные, навыки (фильтр «только изученные»), снаряжение, магия, биография, эффекты.
- Лист чудовища: класс, угроза, награда, броня; параметры, навыки, атаки, магия, знания (поверья / ведьмачьи с СЛ).
- Лист предмета для 6 типов: оружие (эффекты оружия списком), броня по частям тела, снаряжение, магия (5 видов), профессия, раса (черты). Эффекты предметов переносятся на владельца.
- Проверка d10: взрыв на 10, провал на 1 (вычитание из основы, стр. 58/156), Удача (списывается), модификатор, СЛ (успех только если больше); окно броска, Shift — без окна; карточка в чат.
- Инициатива `1d10 + Реа`; раса и профессия у персонажа единственные (бросок новой заменяет старую).
- Полосы токена: ПЗ и Вын.

**Как запускать проверку:** система подключена junction'ом `D:\Witcher\_foundry_test\Data\systems\vedmak → D:\Witcher\vedmak`; сервер —
`node main.mjs --dataPath="D:/Witcher/_foundry_test" --port=30014 --noupnp --noupdate --world=test-vedmak` из `App\resources\app`.
После изменения `system.json` (новые типы документов) сервер нужно перезапустить.

**Рабочий Foundry пользователя:** `tools\sync-to-foundry.ps1` копирует систему в `D:\FoundryVTT-WindowsPortable-14.365\Data\systems\vedmak`
(копия, не ссылка — удаление через интерфейс Foundry не заденет исходники). Запускать после каждой итерации.

### 1. Бой ✅ готово (стр. 149–175)
Код — `module/combat/`, справочники — `module/config/combat.mjs`.
- **Атака** (`attack.mjs`): оружие, щит, без оружия, таран. Быстрая/сильная/обычная (СА у чудовищ), разбег, удар эфесом,
  разоружение, подсечка, финт, парное оружие; приёмы Борьбы (захват, обездвиживание, душение, бросок, толчок). Прицельно по
  части тела (штраф), дистанции стрельбы (авто по токенам), обстоятельства (засада, темнота, обездвижена…), доп. действие за 3 Вын,
  статусы атакующего. Рукопашное оружие + удар рукой, бонус урона по Тел для ближнего боя. Крит. провал — таблица последствий.
- **Защита** (`defense.mjs`): уклонение, изменение позиции, блок (−1 надёжности предмета), парирование (−3, атакующий ошеломлён;
  не против стрел, метательное −5), блок рукой (урон в руку), без защиты против СЛ (дезориентация 10, размер цели).
  Вторая и следующие защиты в раунде −1 Вын (кроме активного уклонения). Попадание только если атака больше защиты.
- **Урон** (`damage.mjs`): часть тела d10 (гуманоид/чудовище, духи без ног), сильная ×2, серебро, укрытие, ПБ со слоями брони,
  пробивание/улучшенное пробивание, сопротивление ×½ (броня, чудовище, несеребряное оружие — не стихийное), восприимчивость ×2,
  невосприимчивость, множитель части тела (череп ×4), крит мимо брони. Эффекты оружия по шансу (кровотечение, яд, горение,
  заморозка, ошеломление), «Дезориентирующее» по голове/туловищу, «Разрушающее». «Применить» — через ведущего по сокету:
  ПЗ/Вын, износ брони, крит. ранение предметом, статусы, испытания Уст и против смерти.
- **Криты**: 24 ранения со штрафами по состояниям свежее → стабилизировано → вылечено (автоматически в параметрах и навыках),
  прицельные (1d6), сбалансированное оружие, «органные» у духов → бонусный урон; СЛ стабилизации и лечения, дни заживления.
- **Состояния** (`statuses.mjs`): 19 статусов токена; заморозка и опьянение — через эффекты, остальное — при бросках и в начале хода.
- **Начало хода** (`combat.mjs`): конец ошеломления и активного уклонения, горение по всем частям через броню, кровотечение,
  яд, удушье, кислота; периодические испытания Уст от ран; испытание против смерти при смерти.
- **Испытания** (`saves.mjs`): Уст (d10 < Уст), против смерти (Уст − накопленный штраф + Удача), смерть и поверженный участник.
- **Прочее** (`manual.mjs`, `mounted.mjs`): урон без атаки (падение, бомба по всем частям тела, ловушка), отдых за ход и дни отдыха
  (уход СЛ 14, Лечащее прикосновение +3, заживление ран), проверка управления скакуном/транспортом с таблицами потери управления,
  разбег верхом и таран (+Nd6 × вес цели). Опционально: «Чудовища из книг», «Адреналин».
- Лист: вкладка «Бой» у персонажа и чудовища; у чудовища — таблица частей тела, металл, сопротивления.

Не сделано в бою (перенесено): боеприпасы и перезарядка арбалета как ресурс, автоматический износ надёжности по таблице
крит. провалов (сейчас текстом), укрытие по стенам сцены, групповая инициатива.

### 2. Магия ✅ готово (стр. 99–123, 166–168)
Код — `module/magic/`, справочники — `module/config/magic.mjs`, компендиум — `packs/magic` из `packs-src/magic.json`.
- **Компендиум «Магия (Корник)»**: 124 записи — 65 заклинаний, 28 инвокаций (друид, проповедник, верховный жрец с божествами),
  10 знаков, 15 ритуалов, 6 порч. Текст из корника (стр. 101–121) с номерами страниц, папки по виду и уровню.
  Извлечение — `D:\Witcher\_tools\extract_magic.py` (poppler `-bbox-layout`, колонки и врезки по координатам),
  сборка — `node tools/build-packs.mjs` (Foundry с системой должен быть остановлен).
- **Сотворение** (`cast.mjs`): Воля + Сотворение / Проведение ритуалов / Наведение порчи; переменные затраты (знаки до 7),
  фокус в руках (посох — эффект оружия, амулет — поле снаряжения; −N, минимум 1), Энергия за раунд боя, перегрузка
  (5 ПЗ за очко + стихийный эффект), место силы (+5 Энергии, +2), двимерит (−1 Энергии за единицу), Вын 0 → дезориентация.
  Магический провал: 1–6 урон и срабатывает, 7–9 не срабатывает + стихийный эффект, >9 ещё и взрыв фокуса; у жрецов — смешанный.
  Ритуалы: СЛ, помощники (−1 СЛ, до 4), провал — ингредиенты потрачены, крит. провал — 1 урон за Вын; концентрация при
  прерывании (СЛ 15/18/16). Порча: крит. провал — 50% на наводящего.
- **Цели и защиты**: кнопки защиты по заклинанию — уклонение/позиция, блок щитом, Сопротивление магии, Воля ×3, «без защиты»
  (срабатывает, если сотворение не провалено). Урон через общий конвейер боя: `@sta` и `@margin` в формулах, мимо брони,
  урон Вын, криты только у «физической» магии, чудовищное «несеребряное» сопротивление к магии не применяется.
- **Эффекты** (`effects.mjs`): статусы по шансу (Аард: 10% + 10% за Вын), по вложенной Вын (Проклятая болезнь),
  с длительностью в раундах; регенерация (Магическое исцеление, Ритуал жизни, Благословение исцеления); щиты Квена и
  Активного щита поглощают урон от блокируемых атак; поддержание активных заклинаний списывает Вын в начале хода.
- Лист: вкладка «Магия» — Энергия раунда, фокус, щит, поддерживаемые заклинания, кнопки «Сотворить/Провести/Навести»;
  лист заклинания — все поля и автоматизация.

Не сделано в магии (перенесено): Рассеивание как защита-состязание, зоны действия через Region, эффекты двимерита при касании
(таблица есть в справочнике). Изучение магии за О.У — сделано на этапе 3.

### 3. Персонаж ✅ готово (стр. 20–71, 124, 237–245)
Код — `module/character/` (advancement, lifepath, wizard), справочники — `module/config/character.mjs` и `module/config/lifepath-tables.mjs`,
компендиумы — `packs/races`, `packs/professions` из `packs-src/*.json` (генераторы `D:\Witcher\_tools\gen_character_packs.py`, `gen_lifepath.py`).
- **Расы** (4): черты текстом + модификаторы строками (параметр/навык/бонус/предел/врождённая броня). Ведьмак: +1 Реа и Лвк, −4 Эмп
  (не ниже 1, не выше 6), +1 Внимание; эльф: +1 Искусство, +2 Стрельба из лука; краснолюд: врождённая ПБ 2 (прибавляется к любой броне
  и не разрушается), +1 Сила, +25 Вес, +1 Торговля; человек: +1 Дедукция, «Доверие» галочкой в окне броска.
- **Социальный статус**: таблица территорий × группы (люди, эльфы, краснолюды, ведьмаки, маги), худшее отношение из групп персонажа,
  «опасение» (шрам, поступки). Территория — настройка мира, у персонажа можно переопределить. Модификаторы (терпимость −1, ненависть −2,
  опасение +1 Запугивание/−1 Харизма) — отключаемой галочкой в окне проверки социальных навыков.
- **Профессии** (9): определяющий навык, Энергия, навыки и навыки на выбор, стартовая магия (квоты), снаряжение на выбор и особое,
  капитал N × 2d6, доступные расы, **древо 3 × 3** с полными текстами способностей и таблицами с полей. Очки древа хранятся в предмете
  профессии на персонаже. Механика: Магический источник (+1 Энергии за 2 очка), Божественная сила и Единение с природой (+1 за очко),
  Укрепление связи (+2 за очко), Крепкий желудок (+5% порога токсичности за очко — так на 10 уровне выходит 150%, как в книге).
- **Вкладка «Профессия»**: определяющий навык и три ветви, броски способностей (параметр + значение), замки «нужно 5 очков в предыдущей».
- **Развитие за О.У** (режим развития на вкладках): навык — текущий уровень (новый 1), сложный ×2, максимум 10; параметр — ×10,
  максимум 10; способности древа — как навыки, по порядку ветви. Начисление О.У ведущим. Журнал в чат.
- **Изучение магии**: при перетаскивании заклинания — «изучить за О.У» (10/20/30/40, порча по опасности) или «просто добавить»;
  время, СЛ и число проверок в чат; Энергия 0 — нельзя; маг — заклинания/ритуалы/порча/знаки, жрец — инвокации/ритуалы/порча/знаки,
  ведьмак — только знаки.
- **Мастер создания** (кнопка на вкладке «Профессия» и в шапке нового персонажа): раса → происхождение (регион и родина бросками,
  +1 навык, родной язык 8) → жизненный путь (семья, родители, положение семьи, друг, братья и сёстры, события за каждые 10 лет,
  стиль, ценности; у ведьмака — школа, тренировки, Испытание травами с модификаторами, десятилетия с уровнем риска, опасности,
  выгоды, союзники, охоты, раны, враги) — каждый результат перебрасывается или выбирается из списка → профессия (ограничения рас,
  навыки на выбор) → параметры (очки 60/70/75/80 или 9 × d10 с перебросом 1–2) → навыки (44 очка, 1–6, сложные ×2; освоенные
  Инт + Реа) → стартовая магия → капитал и снаряжение → итог. Применение: параметры, навыки и отметки профессии, раса, профессия
  с определяющим навыком, магия из компендиума, предметы по названию (из компендиумов, иначе простое снаряжение), биография,
  внешность, характер, ценности, школа, кроны, репутация, Удача, штрафы ран эффектом «Жизненный путь», зависимости.
- **Школы ведьмаков**: Волк — без штрафа сильной атаки, Змея — без штрафа парного оружия, Грифон +2 Энергии, Медведь −2 СД, Кот — текстом.
- **Репутация** (бросок d10 ≤ репутации), **Удача** (восстановление на новую партию), **зависимость** (d10 < Воля − дни без дозы,
  статус «Ломка» −5 ко всем проверкам, доза сбрасывает).

Не сделано в персонаже (перенесено): покупка снаряжения за кроны в мастере (нужен компендиум снаряжения — этап 6), счётчик
«Упрямства» людей, наставник и практика как источник О.У (О.У начисляет ведущий), автоматические бонусы «+2 к Подготовке ведьмака
против класса чудовищ» (записываются текстом).

### 4. Ремесло и алхимия ✅ готово (стр. 71–97, 125–147, 246–265)
Код — `module/crafting/` (craft, alchemy, enhancements), справочник — `module/config/crafting.mjs`. Новые типы предметов:
компонент, чертёж/формула, алхимия, усиление. Извлечение таблиц — `D:\Witcher\_tools\extract_equipment.py` (колонки по
координатам слов), сборка источников — `gen_crafting_packs.py` (ручные исправления перепутанных вёрсткой строк, ингредиенты
формул распознаны по значкам субстанций с увеличенных страниц).
- **Компендиумы** (из этапа 6 перенесены сюда, потому что ремесло без них бессмысленно): «Оружие» 70 (люди, Старший Народ,
  ведьмачьи мечи, 14 реликвий с легендой кратко и СЛ Образования), «Броня и щиты» 47 (по частям тела, Старший Народ,
  3 доспеха-реликвии), «Снаряжение» 104 (инструменты с видом набора, стандартное, ёмкости, еда, одежда, скакуны и упряжь,
  боеприпасы, медальон), «Компоненты и ингредиенты» 114 (с субстанцией, местом, количеством и СЛ собирания),
  «Алхимия» 82 (22 состава, 12 эликсиров, 12 масел, 10 отваров, 12 мутагенов, 8 бомб, 6 ловушек), «Усиления, руны и глифы» 22,
  «Чертежи и формулы» 201 (все чертежи с компонентами, доплатой и ценой, все формулы с субстанциями).
- **Изготовление**: окно с наличием компонентов/субстанций и инструментов, кузница для металла, чертёж перед глазами +2,
  доплата кронами вместо материалов, Рем + Изготовление/Алхимия против СЛ; материалы тратятся и при провале, кнопка
  «Переработать» (та же СЛ: половина материалов, у формулы — одна субстанция). Субстанции берутся из самых дешёвых ингредиентов.
  Результат ищется по названию в компендиумах и складывается с одноимёнными предметами.
- **Починка** (СЛ чертежа − 5, +2 за руну/глиф/усиление, по 1 единице компонентов), **разборка** (½ компонентов, минимум 1),
  **собирательство** (Выживание в дикой природе против СЛ, количество бросается), **запоминание** рецептов (лимит Инт).
- **Алхимия**: «Выпить» — эффект с длительностью (раунды — отсчёт в начале хода, минуты/часы — по мировому времени),
  одинаковые эликсиры не суммируются; токсичность = своё значение + действующие эликсиры/отвары, сверх порога — отравление и
  кнопка «Стойкость СЛ 18» (отменяет последний эликсир); не-мутант проходит Стойкость СЛ 18. Автоматизированы: «Гром» (+3 урона
  физическими атаками), «Зелье Петри», «Полнолуние» (+30 ПЗ), «Ласточка» и отвар тролля (регенерация), «Неясыть», «Иволга»,
  «Белый мёд», отвар накера; остальное — текстом. «Применить» (кровоостанавливающий порошок, нюхательная соль…),
  «Бросить» (Атлетика, зона: цели или все токены в радиусе от одной цели → урон без атаки с шансом эффекта),
  «Установить ловушку» (карточка с кнопкой «Сработала»).
- **Масла**: на выбранное оружие на 30 минут, +5 урона по классу чудовищ (гуманоиды — и по персонажам), выдыхаются по времени.
- **Мутагены**: час и Алхимия против СЛ; постоянные модификаторы (урон в ближнем бою, Реа, Тел, ПЗ, Энергия), не больше двух;
  не-мутант отравлен.
- **Усиления**: набор брони на выбранные части (Изготовление СЛ 14, +ПБ и сопротивления, снять — СЛ 15), руны на оружие
  (эффект оружия в свободную ячейку), глифы на броню. Реликвии дают модификаторы, пока надеты или в руках.
- Лист: вкладка «Ремесло» (токсичность, мутагены, запомненные рецепты, инструменты, действующие эликсиры, алхимия с кнопками
  действий, рецепты с готовностью, компоненты с итогами по субстанциям, усиления); на «Снаряжении» — значки масла, рун,
  усилений, починка и разборка. Мастер создания подбирает стартовое снаряжение из новых компендиумов.

Не сделано в ремесле (перенесено): бонусы глифов к магии (текстом), способности ремесленника и мага («Подмастерье», «Двойная
порция», «Дистилляция», «Адаптация») как галочки в окне изготовления, эффекты отваров сверх перечисленных, услуги и проживание
как справочник, «+3 к месту крита» отвара катакана.

### 4.5. Лист персонажа: разбор и доводка ✅ готово
Полный проход по всем девяти вкладкам (2026-09-17).
- **Шапка**: вместо чисел — полосы ПЗ, Вын и Токсичности. На полосе ПЗ золотая насечка порога ранения, рамка полосы желтеет
  ниже порога и краснеет при смерти; у токсичности своё значение сплошной заливкой, действующие эликсиры — штриховкой.
  Удача, О.У и Репутация — компактным столбиком справа; теги состояния (ниже порога, при смерти, перегруз) рядом с именем.
- **Переносимый вес (стр. 48)** — раньше правила не было: считается вес всего имущества с учётом количества,
  сверх предела (Тел × 10) — по −1 к Реа, Лвк и Скор за каждые полные 5 кг (минимум 1), Бег пересчитывается сам.
  Виден на «Параметрах» (полоса, предел подъёма Тел × 50) и на «Снаряжении» рядом с кронами.
- **Параметры**: вкладка больше не полупустая — добавлены нагрузка и особенности расы; редкие поля («Бонусы к максимумам»)
  свёрнуты; убраны дубли полей, разъехавшихся по вкладкам.
- **Снаряжение**: кроны и нагрузка вверху, снаряжение разбито по категориям книги, количество правится прямо в списке,
  предметы можно брать в руки (фокус мага, инструменты), в строке — вес всей пачки и цена за штуку.
- **Бой**: щиты с прочностью рядом с бронёй по частям тела, скованность подписана, подсказки читаются (исправлен шрифт).
- **Магия**: пустые разделы (инвокации, знаки, ритуалы, порча) больше не занимают место — вместо них строка кнопок
  добавления; колонки таблицы заклинаний перестали рвать текст.
- **Ремесло**: количество компонентов правится на месте, у алхимии в строке видно действие эликсира, токсичность не дублируется.
- **Эффекты**: колонка «Осталось» (раунды, минуты, «постоянный»), истёкшие помечены.
- Девять вкладок влезают в одну строку при ширине листа 880+; при уже — переносятся, а не обрезаются.

### 4.6. Боевой худ и структура вкладок ✅ готово
- **Боевой худ** (`module/apps/combat-hud.mjs`) — полоса внизу экрана, встроенная в нижнюю панель Foundry над макробаром.
  Появляется, когда бой начат, и уходит, когда бой удалён; выключается в настройках («Боевой худ», своя для каждого игрока),
  сворачивается стрелкой (состояние запоминается). Показывает того, кем играешь: игроку — выделенный токен или его персонажа
  (защищаться нужно и на чужом ходу), мастеру — выделенный токен, иначе того, чей ход.
  Содержимое: портрет (клик — лист), раунд и чей ход, полосы ПЗ, Вын и Токсичности с насечкой порога ранения, снимаемые
  значки состояний, кнопка «Ход»; ниже — атаки тем, что в руках (у чудовищ — когти и клыки), четыре защиты с основой,
  испытание Уст, «против смерти» при ПЗ ниже нуля, отдых и урон без атаки, знаки и заклинания с ценой в Вын,
  алхимия с количеством. Кнопки бросают то же, что и лист; Shift — без окна.
- **Структура вкладок листа** (переделана, см. 4.16): один ряд вкладок и постоянная колонка слева.
  Шаблоны вкладок берут свою группу из `{{tab.group}}`/`{{tab.id}}`, поэтому один и тот же файл работает
  и у персонажа, и у чудовища.

### 4.7. Переоформление вкладки «Лист» ✅ готово
- **Параметры**: сверху во всю ширину полоса из девяти больших карточек — название, крупное итоговое значение
  (клик — проверка), под ним база и модификатор (ноль показан точкой); «Удача» отмечена золотом, в режиме развития
  кнопка «+ О.У» встаёт в подвал карточки. Ниже во всю ширину производные, под ними особенности расы.
  Нагрузка осталась только на «Снаряжении», ручных счётчиков нет вовсе: штраф испытаний смерти растёт сам и
  обнуляется при выходе из «при смерти», щит ставит и тратит Квен, адреналин капает за крит при включённом правиле
  (настройка «Адреналин»). Производные разложены по смыслу —
  «Движение» (бег, прыжок, подъём), «Стойкость» (устойчивость, отдых, порог ранения), «Дух» (энергия, решительность),
  «Рукопашная»; вместо сетки плиток — подпись и число, разделённые волосяными линиями. Ручные бонусы к максимумам
  свёрнуты в подвале той же панели.
- **Эффекты**: сюда переехали все состояния. Сверху — то, что действует сейчас, отдельными значками с крестиком,
  ниже полная сетка «поставить или снять»; затем таблица активных эффектов с длительностью. На «Бое» состояний больше нет,
  там же убрана осиротевшая «Скованность» (она подписана в заголовке брони).

### 4.8. Свой лист активного эффекта ✅ готово
Путей данных (`system.stats.ref.mod`) на виду больше нет — `module/sheets/effect-sheet.mjs` + `module/config/effects.mjs`.
- Окно эффекта — своё, по-русски и в стиле системы: вкладки «Изменения», «Длительность», «Описание».
- **Изменения**: три колонки — «что меняет» (выпадающий список: параметры, навыки по параметрам, максимумы,
  бонусы к урону), «как» (прибавить, вычесть, умножить, заменить, не ниже, не выше) и «насколько». Кнопкой можно
  переключить строку на свой путь данных для редких случаев. Значение всегда несёт одно скрытое поле — иначе форма
  склеивает два одноимённых поля в «ключ,».
- **Длительность**: сколько и чего (раунды, ходы, минуты…), когда истекает; **Описание**: выключен, перенос с предмета,
  состояния и текст.
- В списках эффектов на листе персонажа и предмета изменения печатаются словами: «Реакция −1», «Урон любыми атаками +3».

### 4.9. Оформление: кожа и железо ✅ готово
Прежний вид был интерфейсным: заголовки шли Modesto Condensed (шрифт D&D 5e из поставки Foundry), текст — Signika

  Оба под SIL OFL, лежат в `fonts/` вместе с текстами лицензий, подключены через `@font-face` — интернет не нужен.
- **Гамма тёплая**: зола `#16120D`, кожа `#2A2119`, железо `#6B5C42`, кость `#DED3BB`, потемневшее золото `#B4914E`,

Перенесена вся магия дополнения — 128 записей поверх 128 корниковых, компендиум «Магия» вырос вдвое.

### 4.15. Материалы листа ✅ готово
Фактур стало четырнадцать вместо восьми, и они разошлись по листу так, что каждая часть выглядит

  и таблицы внутри берут их сами — новый раздел добавляется одной строкой.
- **Остальное по мелочи, но заметно:** шапка листа и кожаные закладки — тиснение, планка вкладок,
  жёлоба полос ПЗ/Вын/Токсичности, шкала нагрузки, лента шагов мастера и планка окна — вороненая
  сталь, подвкладки — холст, счётчики удачи и О.У. — литая бронза, бирки у имени — латунь,
  производные значения — камень, шапки таблиц — бронзовая патина, карточки бросков в чате — волокна
  старой бумаги, окно броска и поля карточки предмета — кожа и пергамент.
- **Производные переложены в сетку.** Раньше значения стояли в ряд без плашек, растягиваясь на всю
  ширину, и число их в группах разное — колонки не совпадали по вертикали, а у «Духа» половина строки

  (значение фокусирующего предмета), чтобы ряд не зиял пустотой. На узком листе панель сама
  переходит на две колонки — через `@container`, а не по ширине экрана: лист живёт в окне.
- **Почему фактура была не видна.** Панели были темнее фона (#2a2119), а режим `overlay` на тёмном
  почти не даёт разницы. Теперь подложка светлее (#3a3022), а сверху лежит притеняющий градиент:
  тон остался прежним, зато зерно читается. Плюс мелкое зерно кожи на панели выглядело шумом —
  для подложек взято тиснение с более крупным рисунком.
- **Как собрано.** `_tools/fetch_textures.py` тянет карты рельефа с ambientCG (CC0) и сводит их
  к серому вокруг среднего тона; у каждой фактуры своя сила зерна — фон под текстом мягкий,
  а тиснение и ковка выразительные. Гладкие ассеты (разброс яркости меньше 5) отбракованы:
  Metal032 и Metal038 давали почти плоскую заливку, их заменили на Metal009 и Metal029.
  Все 14 картинок — 440 КБ на весь набор, список с источниками — `assets/textures/ИСТОЧНИКИ.txt`.

  плашки на невысоком листе), под ним по центру имя и метки (раса, профессия, социальный статус), тревожные
  состояния («при смерти», «ниже порога», «перегруз»), полосы ПЗ/Вын/Токсичности, счётчики Удачи, О.У.
  и Репутации (столбиком, подпись слева, число справа) и четыре значения, которые спрашивают каждый ход, —
  Энергия, Устойчивость, Порог ранения, Бег. Счётчики и значения оформлены так же, как таблички параметров:
  чеканная рамка с засечками по углам, фактура, крупное число.
  Внизу кнопки «Развитие» и «Мастер»: режим развития включается один раз и виден с любой вкладки; если
  колонка не влезла по высоте, кнопки прилипают к нижнему краю и получают подложку. Блоки разложены
  по всей высоте (`justify-content: space-between`) — иначе всё жалось к верху, а низ зиял пустым полем.
- **Вкладок семь, все одного уровня**: Параметры, Бой, Навыки, Снаряжение, Ремесло, Магия, Дневник.
  Подвкладки разошлись по смыслу: характеристики и производные — на «Параметрах», состояния и активные
  эффекты — в «Бою», древо профессии — в «Навыках», особенности расы — в «Дневнике», «Ремесло» стало
  самостоятельной вкладкой, чтобы «Снаряжение» не превращалось в бесконечную прокрутку.
- **«Параметры» больше не сжаты и не пустуют**: девять табличек лежат в два ряда по пять (в один ряд
  подписи вроде «Телосложение» ужимались до нечитаемых), а панель производных тянется на всю оставшуюся
  высоту вкладки — плашки выше, цифры крупнее, поля снизу нет.
- **Как устроено**: `.window-content` персонажа — сетка из двух колонок; колонка занимает обе строки,
  полоса вкладок и содержимое — вторую. Общие куски вынесены в `parts/effects.hbs` и `parts/profession.hbs`,
  поэтому лист чудовища по-прежнему открывает эффекты отдельной вкладкой и не знает про колонку.
  Ширина листа по умолчанию — 1040×860.

### 4.17. Окна проверок ✅ готово
Окна перед броском были обычными формами Foundry: подписи слева, выпадающие списки справа, «Public as
User» по-английски, всё одинаково важное. Теперь окно собрано как боевая карточка: сверху что бросаем
и основа броска, посередине только то, что игрок выбирает, снизу — во что сложится бросок.
- **Шапка** (`parts/head.hbs`): крупное название, строка слагаемых («Интеллект 7 · Внимание 5») и
  плашка «ОСНОВА» с числом. У атаки в заголовке стоит цель, у защиты — кто и чем бьёт, у сотворения —
  вид магии и стихия. Плашка живая: выбрал другой вид атаки или другую защиту — число меняется.
- **Выпадающие списки заменены кнопками**: вид удара, часть тела, вид защиты, скакун — кнопки-радио,
  обстоятельства, дистанция и помехи — жетоны-переключатели. Видно всё разом, без открывания меню,
  и клавиатурой работает как обычная радиогруппа.
- **Удача — жетоны** вместо счётчика: кружки заполняются до выбранного, рядом «потрачено 2 из 4».
  Вложенная Выносливость в сотворении — столбики, под ними живая строка «урон 4d6 · Горение 50%»,
  ниже полоса Энергии за раунд с красной штриховкой перегрузки и ценой перебора.
- **Подвал** (`parts/total.hbs`): «БРОСОК d10 + 16 + 5», рядом «УРОН 2d6+2 + 2», справа порог, если он
  есть («Нужно больше 20»), и подсказка «Shift — бросить сразу, без окна». Подвал прилипает к низу,
  кнопки окна продолжают его: золото — проверка, кровь — атака, фиолет — магия.
- **Выбор сложности убран.** СЛ задают правила вызова, окно лишь показывает порог справкой; у ритуала
  и ремесла СЛ приходит из самого рецепта или обряда.
- **Обстоятельства сворачиваются** (атака и защита): в заголовке свёрнутого блока — сводка отмеченного
  («· Засада +5»), чтобы закрытый блок не прятал правки, уже влияющие на бросок. Выбор «свёрнуто /
  раскрыто» запоминается во флагах пользователя (`folds.attackSituations`, `folds.defenseSituations`);
  по умолчанию блок свёрнут.
- **Модификатор урона.** У атаки и сотворения рядом с правкой броска появилось второе поле — правка
  урона; она уходит в формулу карточки и в заметку «Правка урона: +2».
- **«Кому видно» по-русски**: Всем, Ведущему, Себе и (только у ведущего) Втёмную — кнопки с иконками
  вместо английского списка ядра.
- **Как устроено**: `module/dice/dialog-ui.mjs` — общие части (Удача, видимость, чтение полей) и живой
  пересчёт. Разметка объявляет `data-base`, `data-mod`, `data-dmult`, `data-dc`, а пересчёт сам
  складывает основу, правки и Удачу, поэтому окно нигде не считает отдельно от броска. Где основа
  зависит от нескольких полей (защита: вид плюс чем блокируем), окно передаёт свою функцию.
  Стили — раздел `.vedmak-dialog.check-dialog`, старые окна в нём не участвуют.
- **Переведены все окна с броском**: проверка навыка и параметра, атака, защита, «без защиты»,
  сотворение, урон, урон без атаки, управление скакуном, изготовление, испытание против смерти,
  дни отдыха.

### 4.18. Параметры и колонка: второй заход ✅ готово
Девять плиток параметров лежали рядами 5 + 4 и обрывались дырой, двенадцать ячеек «Производных»
занимали половину вкладки, а колонка была списком из шести блоков одного веса. Переделано по макету
(канва «Параметры и колонка листа»).
- **Параметры — два столбца по смыслу**: ТЕЛО (Телосложение, Реакция, Ловкость, Скорость) и РАЗУМ
  (Интеллект, Воля, Эмпатия, Ремесло), по четыре строки — сетка ровная. Удача ушла вниз отдельной
  строкой «Судьба»: она не бросается как параметр, её тратят.
- **Строка параметра** читается слева направо: клеймо с итоговым числом, название и под ним — за что
  параметр отвечает («знаки, сопротивление магии», «бег 12 м · прыжок 2 м») или откуда взялась разница
  с вложенным («6 вложено, −5 от расы и эффектов», «ниже порога ранения: вдвое»), справа поле базы.
  Клеймо краснеет, когда параметр срезан, и зеленеет, когда поднят. Бросок — по всей строке;
  в режиме развития на место поля встаёт кнопка «+» с ценой в О.У.
- **Полоса режима развития**: сколько О.У. осталось, почём следующий шаг и кнопка выхода — раньше
  режим было видно только по кнопке в колонке.
- **Производные** — четыре списка с точечным заполнителем вместо двенадцати одинаковых плиток: глаз
  идёт по строке от названия к числу, блок занимает вдвое меньше высоты, а ряды разведены по остатку
  вкладки (`align-content: space-evenly`), чтобы снизу не зияло пустое поле.
- **Колонка**: имя вписано на портрет (отдельная строка съедала высоту), под ним метки, затем
  тревожные состояния лентами с иконкой и своим цветом, и только потом жизнь — полосы толще, с
  делениями по четвертям и золотой риской порога ранения, число крупное, максимум мелким. Удача —
  жетоны, те же, что в окнах бросков. О.У. и Репутация стали тихими строками с заполнителем, а
  Энергия, Уст, Порог и Бег — одной шкалой на четыре деления внизу.
- **Как устроено**: `STAT_GROUPS` и поле `about` у параметров — в `config/stats.mjs`; контекст листа
  собирает `statGroups`, `luckStat` и `luckDots`. Колонка берёт свой `parts/vitals-rail.hbs`
  (лист чудовища остался на общем `vitals.hbs`), новые стили висят на `.vedmak.character`, поэтому
  таблица параметров чудовища не затронута. На узком листе (< 34rem) столбцы и списки встают
  в одну колонку через `@container`.

### 4.19. Вкладка «Бой» ✅ готово
Вкладка отвечала на три вопроса вперемешку: атаки таблицей на восемь колонок, защиты и испытания
одинаковыми плашками, броня таблицей, а сетка из двадцати состояний висела раскрытой всегда.
Переделано по макету (канва «Вкладка «Бой»»): вкладка читается сверху вниз — чем бью, чем отвечаю,
что со мной.
- **Чем бью** — строка оружия вместо таблицы: иконка, название и чем оно примечательно (масло,
  серебро, свойства, дистанция), шкала надёжности, основа и урон крупно, справа кнопка «Атака»
  (у дальнобойного — «Выстрел») цвета крови. Кровавая кромка — оружие в руках; пунктир и тусклый
  тон — лежит в мешке, у такой строки вместо атаки «В руки». Естественное оружие чудовищ (когти,
  клыки) считается готовым всегда. Адреналин — одной полосой под оружием.
- **Чем отвечаю** — четыре защиты строками с основой клеймом и пояснением («уйти с линии удара»,
  «изменение позиции: шаг на ½ Скор»); испытания отдельно: Уст спокойное, против смерти кровавое,
  с подписью о накопленном штрафе. Действия хода — жетоны в один ряд, у отдыха видно, сколько вернёт.
- **Броня** — справа от защит, шесть строк со шкалой прочности на общей шкале (видно, где дыра),
  множитель части тела рядом, голова ×3 красным; ниже слои, сопротивления и щиты.
- **Что со мной** — действующие состояния жетонами с ценой (первая фраза подсказки), полная сетка
  раскрывается кнопкой «Отметить состояние». Критические ранения — карточки с уровнем, местом и
  выбором состояния раны. Активные эффекты — строки с заполнителем вместо таблицы.
- **Как устроено**: шаблон общий для персонажа и чудовища, поэтому стили висят на `.vedmak .combat-tab`;
  у чудовища эффекты остаются на своей вкладке. Контекст боя дополнен в `actor-sheet-base.mjs`
  (масло, серебро, свойства, шкалы брони, цена состояний). На узкой вкладке (< 34rem) колонки
  встают в одну через `@container`.

### 4.20. Карточки бросков в чате ✅ готово
Итог стоял внизу под таблицей слагаемых, заголовки капсом ломались на две строки, исход кричал
плашкой во всю ширину, пять кнопок защиты были иконками без подписей, а светлая бумага не вязалась
с тёмными окнами бросков. Карточки собраны в языке окон.
- **Шапка**: иконка, название, подзаголовок и справа итог клеймом с подписью — «атака», «защита»,
  «против 15», «ПЗ», «нужно < 6». Урон — кровавым числом, магия — фиолетовым, крит — золотым.
- **Кости и сумма** одной строкой под шапкой («основа 16 + 9»), разбор слагаемых свёрнут под
  «из чего сложилось». Крит и провал — бирки с иконкой.
- **Исход** — спокойная лента с кромкой («Попадание · атака выше на 10», «Защита удалась»), а
  кромка всей карточки слева говорит, чем кончилось: золото, зелень или кровь.
- **Кнопки защиты подписаны** (Уклон, Позиция, Блок, Парир., СЛ; у магии — Магия, Воля ×3, Сразу),
  главная кнопка окрашена по делу (Урон, Применить — кровью), вторичные тихие.
- **Сообщение Foundry** вокруг карточки затемнено (`.chat-message:has(.vedmak-card)`), иначе тёмная
  карточка сидела вставкой в пергаменте. Переменные темы открыты и карточкам (`.vedmak, .vedmak-card`),
  потому что в чате они стоят вне листа.
- **Старые сообщения** держат прежнюю разметку (`.card-title`, `.total-row`) — эти классы оформлены
  в том же духе, поэтому история чата не ломается. Простые карточки из кода (`util.postCard`,
  отдых) переведены на новый каркас.

Колонки навыков были неравной высоты с дырами между группами, в строке три похожих элемента

### 4.24. Разбор кода и данных (30.09) — очередь правок
Проверено без Foundry и в порядке:
- синтаксис всех модулей и их импорты;
- 61 путь к шаблонам и все подшаблоны, хелперы Handlebars;
- кнопки `data-action` против обработчиков листов, настройки;
- все 3315 документов `packs-src` против схем `TypeDataModel` — ни одного лишнего поля и ни одного неверного типа;
- 3530 ссылок между компендиумами;
- производные параметры и проверка d10 против стр. 47–48 и 156–157.

**Исправлено в коде:**
- Урон и эффекты заклинания больше не применяются дважды. Раньше `applied` и `effectsApplied` ставились в конце
  обработчика ведущего, а кнопка у игрока снова активна сразу после отправки запроса. Двойной клик или клики
  атакующего и владельца цели разом наносили урон дважды. Теперь ведущий помнит карточки в работе
  (`applyingMessages` в `damage.mjs`), повторный запрос пропускается.

**Исправить в данных бестиария** (в `bs_*.py`, не в `packs-src`):
- **Восприимчивость к яду у 153 гуманоидов.** Строка уязвимостей «Яд повешенного» — это *масло* против
  гуманоидов, а импорт прочёл её как восприимчивость к урону ядом. Из-за этого отравленный НИП теряет 6 ПЗ за ход
  вместо 3, и любой урон ядом по нему удваивается (`effectMult` в `combat.mjs`, `damage.mjs`). Масло по гуманоидам
  и так работает через класс, поэтому ключ `poison` у них нужно убрать.
- **Таблица частей тела непоследовательна.** Человеческую таблицу получили 250 из 275 существ. Среди них 36 зверей
  (лиса, лошадь, крыса, вол, лось), духи, трупоеды, огры, вампиры. При этом волк и собака бьются по таблице
  чудовища. У модели по умолчанию `bodyType: monster`. Нужно решить правило по стр. 154 и выставлять его в импорте.

**Пробелы — закрыты** (`module/character/race.mjs`):
- **Черты расы при переносе на готовый лист.** Естественное оружие расы (`grants`: клыки врана, зубы
  боболака) теперь выдаётся и тогда, когда расу перетаскивают на готового персонажа, а не только в мастере.
  При смене расы уходят её естественное оружие (категория «естественное», имя из `grants`) и эффекты черт.
  Мастер убирает их у прежней расы так же, поэтому повторный запуск мастера не плодит клыки.
- **Гном, «Внимание к деталям».** Окно выбора трёх навыков Ремесла: после третьей галочки остальные гаснут.
  Выбор ложится эффектом черты +2 (`flags.vedmak.raceTrait = "detail"`), повторный выбор заменяет прежний.
  Окно появляется при переносе расы на лист и в конце мастера. В тексте черты в `races.json` ещё осталось
  «впишите в их поправку» — поправить в генераторе рас.
- **Словесная дуэль** — настройка мира `verbalDuel`, по умолчанию включена. Если выключить, на вкладке «Бой»
  останется только обычный бой, а блок социального статуса (`parts/social-status.hbs`) встанет под ним:
  статус действует на социальные проверки и без дуэли.

**Пробелы — остались:**
- **Покупка снаряжения за кроны в мастере** была отложена до компендиума снаряжения. Теперь он есть
  (416 записей), так что это можно делать.
- **Уточнить по книге:** порог ранения считается как ПЗ/5. Бонусы к ПЗ («Полнолуние» +30, мутагены)
  поднимают и порог, хотя по формуле стр. 48 он растёт из (Тел + Воля) / 2.
- Если расу удалить с листа кнопкой, а не заменить другой, её клыки и эффект черты останутся.

**Защита сокета.** `applyDamage` и `applySpellEffects` теперь проверяют на стороне ведущего две вещи: запрос
прислал ведущий, атакующий или владелец цели (как у кнопки), а карточку в чате создал владелец атакующего.
Иначе карточку можно подделать из консоли (`userOwnsAny` в `common.mjs`).
`applyManualDamage`, `setStatus` и `applyResolve` по-прежнему выполнят запрос любого игрока. Там игрок
законно действует на чужие токены: бомба, парирование, дуэль. Поэтому проверка владения не годится —
нужно сверять запрос с карточкой в чате, а это переделка протокола.

### 4.26. Выпуски и установка по ссылке ✅ готово
Автор решил сделать репозиторий публичным, чтобы систему можно было ставить в Foundry по ссылке-манифесту
`https://github.com/oralcum61-maker/Vedmak/releases/latest/download/system.json`.
- **Сборка выпуска** — `tools/release.mjs`. Копирует файлы из git в `dist/` без служебного, без `packs-src`
  и без жетонов `assets/tokens/`: 2-Minute Tabletop запрещает их раздавать. Жетоны в бестиарии заменяются
  портретами (270 существ; у «Рабочего» портрет тоже из жетонов — там силуэт Foundry), бестиарий
  пересобирается. В `system.json` проставляются версия, `manifest` на последний выпуск и `download`
  на архив именно этой версии.
- **Выпуск** — `.github/workflows/release.yml`, кнопкой Run workflow (тег ставится сам) или тегом `vX.Y.Z`:
  проверка версии и `check.mjs`, сборка, архив,
  GitHub Release с `system.json` и `vedmak.zip`. Порядок — навык `/release`.
- В `system.json` репозитория — `url`, `manifest`, `download` на последний выпуск; в `README` — раздел «Установка».
